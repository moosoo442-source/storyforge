StoryForge — 단일 파일 버전
  ================================

  쓰는 법 (GitHub Pages):
  1. github.com 에 새 저장소(repo) 만들기  (이름 아무거나, 예: storyforge / Public)
  2. 저장소 화면에서 "uploading an existing file" 클릭
  3. 이 zip 안의 index.html 파일 하나만 업로드 → Commit
  4. 저장소 → Settings → Pages
     - Source: Deploy from a branch
     - Branch: main / (root) → Save
  5. 1~2분 뒤 https://<유저명>.github.io/<저장소이름>/ 접속

  이게 전부예요. 다른 파일 필요 없습니다.
