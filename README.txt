StoryForge — 단일 파일 (v5)
  ============================

  GitHub Pages 올리기:
  1. github.com 새 저장소(Public) 생성
  2. "uploading an existing file" → index.html 한 개 업로드 → Commit
  3. Settings → Pages → main / (root) → Save
  4. 1~2분 뒤 https://<유저명>.github.io/<저장소이름>/ 접속

  이미 v4를 올려두셨다면 index.html 만 새 파일로 덮어쓰기 → 끝.
  기존 데이터(인물·세계관·원고)는 그대로 호환됩니다.

  【v5 새 기능】

  👁️ 관람모드 (스펙테이터 모드)
  - 사이드바에 "관람모드" 메뉴 추가
  - 편집 UI 없이 깔끔하게 정리된 위키 페이지로 보여줌
  - 왼쪽 고정 목차(TOC) + 자동 스크롤 강조
  - 인쇄/PDF 그대로 가능

  📤 정적 HTML 출력 (공유용)
  - 프로젝트 → "📤 정적 HTML 출력" 버튼
  - 자체 완결된 단일 HTML 파일 생성
  - 다른 곳에 올리거나 누구에게 보내도 그대로 열림
  - TOC, 인물, 세계관, 타임라인, 용어집, 원고 전부 포함

  📑 세계관 양식 10종
  - 자유 / 장소 / 마법체계 / 조직 / 종족 / 종교
  - 역사 사건 / 유물 / 언어 / 생물(몬스터)
  - 양식별로 미리 정해진 항목(기후·수장·외형·교리 등)
  - 각 항목에 자유 메모 + 이미지도 추가 가능

  📕 용어집 / 사전 페이지 (신규)
  - 고유명사·전문용어 사전 형태로 정리
  - 가나다 순 자동 그룹화
  - 검색, 별칭, 분류 태그 지원

  🎨 디자인 전면 개편
  - 새 색감, 그라디언트 브랜드 마크
  - 카드/버튼/탭/입력 전부 다듬음
  - 부드러운 마이크로 인터랙션
  - 반응형 폰트(clamp), 모바일에서 더 큰 터치 영역

  📱 모바일 하단 네비게이션
  - 모바일에서 화면 하단 고정 메뉴
  - 프로젝트 안에서는 5개(홈/원고/인물/세계관/관람)
  - 대시보드에서는 3개(홈/검색/설정)

  🌈 테마 11종 (2종 추가)
  - 기존 9종 + 민트 + 사이버펑크(네온)

  🛠 그 외
  - 프로젝트 단위 JSON 백업 (전체 백업과 별개)
  - 단일 프로젝트 JSON 가져오기 (기존 데이터 보존)
  - 빠른 검색에 용어집 항목도 포함
  - 모든 라우트 반응형 점검 완료
  - 자동 점검 39개 항목 전부 통과

  【가게에 올리는 사용자에게 한마디】
  - 데이터는 이 브라우저에만 저장됩니다
  - 기기 옮길 때는 [설정 → JSON 백업/복원] 사용
  - 단순히 보여주기만 하려면 [정적 HTML 출력]을 다른 저장소에 올리세요
